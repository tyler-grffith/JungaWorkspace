Here is a full example of a complicated engineering problem that I used Desmos to model. 

Note sliders are used to allow the user to interact with the model

The slideers at the top level are meant the the end user to interact with

The sliders under paramters are more for the model author to tweak.

Note some sliders under parameters represent constants so I set the upper and lower bound to be the same. Our application should support both constants and sliders.

This is a good example for Desmos' limitation on labels. I would like labels to be attched to the plot lines.
